# 📚 Second-Hand Book Marketplace

A full-stack e-commerce platform where users can buy and sell second-hand books.

## 🚀 Live Demo
*Coming soon - deployment in progress*

## ✨ Features

- 🔐 **User Authentication** - Secure login/register with JWT
- 📖 **Book Listing** - Browse and search books with filters
- 🛒 **Shopping Cart** - Add/remove items, manage quantities
- 💳 **Payment Integration** - iyzico payment gateway
- 👤 **User Profile** - Manage personal info and order history
- 🎨 **Responsive Design** - Works on all devices
- 🔍 **Search & Filter** - Find books by title, author, category, price

## 🛠️ Tech Stack

**Backend:**
- ASP.NET Core 8
- Entity Framework Core
- ASP.NET Core Identity (Authentication)
- Microsoft SQL Server
- LINQ

**Frontend:**
- Razor Pages
- Bootstrap 5
- JavaScript
- HTML5/CSS3

**Tools:**
- Git/GitHub

## 🏃‍♂️ Getting Started

### Prerequisites
- .NET 8 SDK
- SQL Server
- Visual Studio 2022 (recommended)

### Installation

1. Clone the repository
```bash
git clone https://github.com/tolgaactn/KitKap.git
cd KitKap
```

2. Update database connection string in `appsettings.json`

3. Run migrations
```bash
dotnet ef database update
```

4. Run the application
```bash
dotnet run
```

5. Open browser: `https://localhost:7XXX`
